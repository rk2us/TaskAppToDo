# TaskAppToDo ✅

A modern **Task Manager Android app** built with **Kotlin, Jetpack Compose, Room, Hilt, and MVVM**.  
Allows users to add, edit, delete, search, filter, and view task details — with smooth navigation and native date/time pickers.

---

## 🚀 Features

- ✅ Add / Edit / Delete tasks
- 🧾 Description, Priority, Category support
- 📅 Native Date & ⏰ Time pickers (no keyboard)
- 🔍 Search by name or description
- 🗂️ Filter by:
  - Completed / Incomplete / All
  - Due Today
- 📄 Task Detail View
- 🧠 Built with best practices: Hilt DI, MVVM, Jetpack Compose
- 🎨 Material 3 UI
